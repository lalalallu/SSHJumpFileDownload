# SSH跳板机文件下载器

一个支持通过跳板机连接内网服务器并下载文件的图形界面工具。

## 功能特性

- ✅ **灵活的连接模式**：支持直接连接和跳板机连接两种模式
- ✅ SSH跳板机连接（支持多级跳板）
- ✅ 图形化文件浏览和选择
- ✅ 大文件断点续传
- ✅ 多任务并行下载
- ✅ 实时进度显示
- ✅ 低资源消耗设计

## 系统要求

- Python 3.8+
- 支持系统：Windows / macOS / Linux

## 安装

### 1. 克隆或下载项目

```bash
cd JumpFileDownload
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 启动程序

```bash
python main.py
```

### 连接服务器

1. 点击 **"连接"** 按钮或菜单 **文件 → 新建连接**
2. 在连接对话框中选择连接模式：
   - **直接连接**：直接连接目标服务器（无需跳板机）
   - **通过跳板机连接**：先连接跳板机，再连接目标服务器
3. 填写服务器信息：
   - **主机地址**：服务器IP或域名
   - **端口**：SSH端口（默认22）
   - **用户名**：登录用户名
   - **认证方式**：密码或SSH密钥
4. 点击 **"测试连接"** 验证配置
5. 点击 **"保存并连接"** 建立连接

### 浏览文件

- 在路径栏输入目录路径并按回车导航
- 双击文件夹进入目录
- 点击 **"刷新"** 更新文件列表

### 下载文件

1. 勾选要下载的文件（支持多选）
2. 选择本地保存目录
3. 点击 **"下载选中"** 开始下载

### 下载管理

- **暂停**：暂停正在下载的任务
- **继续**：恢复暂停的下载（支持断点续传）
- **取消**：取消下载任务
- **打开**：下载完成后打开文件

## 配置说明

### 认证方式

支持两种认证方式：

1. **密码认证**：直接输入密码
2. **SSH密钥认证**：选择私钥文件路径，可选输入密钥密码

### 断点续传

- 下载过程中断后，再次下载同一文件会自动从断点继续
- 临时文件保存在目标文件同目录，扩展名为 `.part`
- 下载完成后自动重命名为正式文件名

## 常见问题

### Q: 连接超时怎么办？

A: 检查网络连接和服务器地址是否正确，确保跳板机和目标服务器都可达。

### Q: 认证失败怎么办？

A: 
- 密码认证：确认用户名和密码正确
- 密钥认证：确认私钥文件路径正确，如有密码保护需输入密钥密码

### Q: 下载速度慢怎么办？

A: 
- 检查网络带宽
- 减少同时下载的任务数
- 确认服务器没有限速
